# The playbook's forms used by this run

Three templates of spec-driven-dev-playbook, copied unchanged from its commit `3986553` so that the run
can read them without leaving this repository. They are in Japanese; this run writes English in the
same structure. Do not edit them.

| File | What the run fills in with it |
|---|---|
| [fact-entry.md](fact-entry.md) | the entries it appends to `specs/001-idp-tenant-integration/facts.md` (from F11 on) |
| [verdict-table.md](verdict-table.md) | the annotated PASS, the split verdict and the tally of each goal in `goal-pack/PROGRESS.md` |
| [HANDOFF.md](HANDOFF.md) | `specs/001-idp-tenant-integration/HANDOFF.md` in G6, in the eight parts the goal brief lists |

The other seven templates were used before the run, in the spec folder: the launch brief, the
constitution, the permissions section and the disposition table of spec.md, the plan gates, the
verification checklists of tasks.md, the ledger entries of research.md, and the mapping of
[from-spec.md](../../from-spec.md).
